FES DMS — Style Guide

The reusable design language for the FES DMS product family (VI / Village-Information Data Management System). Use this whenever you add a new product, module, or screen so everything stays visually consistent.

Figma: FES-DMS Blue #1F4397 + Green #39A248 Helvetica · Inter · DM Sans Glass top-nav shell

1 Brand foundations

The two-primary rule

Blue is the default primary — confirm, submit, brand. Green is the generative / positive primary — Add VI, Add New, Active, Approved. Never use green for destructive or neutral actions.

Key patterns

  • Table ⇄ Map duality on every geo module + fullscreen.
  • Detail without navigation — right slide-over panel.
  • Approvals: Pending → Approved / Rejected / Request Changes.
  • Field-User resilience: Offline + Sync-queue states.
  • Filter chip row above lists; selected chip filled.
  • Microcopy: nav UPPERCASE; titles Title Case.

8 Adding a new product / module

  1. Shell — reuse the glass header; add an UPPERCASE nav item with icon (green when active). Respect role scoping (Super Admin / Org Admin / Field User).
  2. Page template — title row → optional 4 stat cards → toolbar → content → pagination. 32px gutters, canvas background.
  3. Tokens only — pull every colour/size from §2–5. No new hexes, radii, or fonts. Blue = confirm, Green = create/positive.
  4. Type — Helvetica for chrome/buttons/labels/inputs, Inter for body/tables, DM Sans only for stat cards. Default 14px.
  5. Components — compose from the inventory. New parts match 12/16/20 radii, the three shadows, and 6/8/12/16 spacing.
  6. Data views — geo records get Table + Map + Fullscreen, status filter chips, row checkboxes, slide-over detail.
  7. Forms — 36px fields, 12 radius, label 12px + asterisk; modal footer Cancel (outline) + Primary (filled).
  8. States — design empty, loading, error, offline, and sync-queue (Field-User contexts).
  9. Status — reuse the badge + semantic colours; always pair colour with a label.
  10. A11y — 14px min body, never colour-only signals, visible focus, AA contrast.
Values marked ≈ (some grays, status hexes, focus/error states) are visually matched — confirm against Figma before shipping, then promote them to ✓. Full token reference and module IA are in FES-DMS-Design-Guidelines.md.
